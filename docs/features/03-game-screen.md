# 03 — Game Screen & HUD

Canonical Notion page: https://app.notion.com/p/3cb8c73f2252810699ebf61652bb9490?pvs=204

## UX contract
The board is the dominant element and the HUD remains minimal.

## Required information
- Current difficulty/opponent label.
- Player identity area.
- Board coordinates if retained after UX approval.
- Resign control.

## Non-goals
No analysis panels, social systems, chat, inventory, profile sidebar, or other chess-platform complexity in MVP.
