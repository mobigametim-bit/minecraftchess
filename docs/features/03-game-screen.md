# 03 — Game Screen & HUD

Canonical Notion page: https://app.notion.com/p/3cb8c73f2252810699ebf61652bb9490?pvs=204

## Playable Slice 1 UX contract
The board is the dominant element and the surrounding HUD stays intentionally small.

## Required information
- Current AI difficulty.
- Computer and player identity strips.
- Turn/check/thinking status.
- Current win reward and non-win reward.
- Resign control.
- Brand control returns to the menu.

## Non-goals
No analysis panel, move engine score, social systems, chat, inventory, profile sidebar, or other chess-platform complexity.
