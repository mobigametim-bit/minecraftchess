# 12 — Responsive & Mobile

Canonical Notion page: https://app.notion.com/p/3cb8c73f225281ab8f20f30dd3d4bd87?pvs=204

## Goal
Keep the board primary and fully usable on desktop and mobile.

## Playable Slice 1 — responsive baseline
- Board stays square and becomes full-width on narrow layouts.
- Player strips and essential game information remain attached to the board flow.
- HUD cards move below the board on mobile.
- Promotion and result overlays adapt to narrow screens.

## Required formal manual target viewports
- 1920×1080
- 1366×768
- 1280×720
- 1024×768
- 390×844
- 360×800

## Acceptance criteria for Feature 12 closure
- No essential control is clipped.
- Board remains square and readable.
- Tap targets remain usable.
- Result overlay fits without blocking required actions.

**Status:** responsive baseline exists for Playable Slice 1; the formal viewport matrix remains a later dedicated acceptance pass.
