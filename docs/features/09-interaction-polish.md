# 09 — Chess.com-Inspired Interaction Polish

Canonical Notion page: https://app.notion.com/p/3cb8c73f2252819183a8dd427f6c82cc?pvs=204

## Intent
Use familiar modern online-chess interaction patterns without copying proprietary visual assets or branding.

## Candidates for UX approval
- Selected-square highlight.
- Last-move highlight.
- Legal-move dots.
- Capture-target treatment.
- Check indication.
- Hover/pressed/focus states.
- Piece-movement animation.
- Capture animation.
- Result-overlay animation.
