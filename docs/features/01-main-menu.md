# 01 — Main Menu & Difficulty Selection

Canonical Notion page: https://app.notion.com/p/3cb8c73f22528100935bdbe97b9d1a46?pvs=204

## Playable Slice 1 UX contract
- First screen is difficulty selection.
- Emerald balance is always visible in the top bar.
- Selecting a difficulty immediately starts a match; no confirmation dialog.
- No login, profile flow, or mode-selection complexity in MVP.
- Five difficulties are used: Новичок, Легко, Средне, Сложно, Эксперт.

## Rewards
| Difficulty | Win | Draw/loss/resign |
| --- | ---: | ---: |
| Новичок | 5 | 1 |
| Легко | 10 | 2 |
| Средне | 20 | 4 |
| Сложно | 40 | 8 |
| Эксперт | 80 | 16 |

## Acceptance checkpoint
This feature is reviewed as part of the playable end-to-end slice rather than as a technical-only intermediate screen.
